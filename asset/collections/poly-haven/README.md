# Poly Haven

Browse 2,370 original-source listings: 521 models, 856 textures and 993 HDRIs. These have not been converted to the current native format.

```sh
grove assets search "wood" --source poly-haven --type texture --availability source
```

Results link the original preview, listing and API download manifest; model and descriptor fields are null. The default ready search excludes them.

Source: [Poly Haven](https://polyhaven.com/) and its [official API](https://api.polyhaven.com/assets). Asset license: [CC0](https://polyhaven.com/license). Preview images remain hosted by Poly Haven.
